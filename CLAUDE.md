# devbox (code-server + shared Traefik)

Docker Compose stack: code-server, **the one Traefik for all local projects**, Portainer. Other repos under
`~/workspace` join it (see "Adding a project" in README.md) instead of running their own Traefik.

## Layout
- `compose.yml`: traefik, portainer, devbox (code-server); one named network `devbox_network` (`NETWORK_NAME`).
- `up.sh`: the entry point. Resolves settings (env, then `.env`, then defaults), generates the password,
  the Traefik dashboard hash (`TRAEFIK_AUTH`), the local CA and leaf cert in `certs/`, and
  `secrets/portainer_admin_password`. Run it instead of bare `docker compose up`.
- `traefik/dynamic/`: file-provider dir, hot-reloaded. `transports.yml` (committed, shared `insecure@file`
  transport) and `tls.yml` (generated by `up.sh`, git-ignored). Docker labels cannot define transports.
- `down.sh`: deletes volumes and the image (destructive, asks for confirmation).
- Git-ignored, never commit: `.env`, `certs/` (holds the CA private key), `secrets/`, `traefik/dynamic/tls.yml`.

## Conventions
- Adding a new setting means touching four places: `setting` line + help text in `up.sh`, the `${VAR:-default}`
  in `compose.yml`, and `.env.example`.
- Router/service names in labels are global across all projects: prefix with the project name.
- `docker compose down` must work without `up.sh`: every `${VAR}` in `compose.yml` needs a default
  (do not use `${VAR:?}`). `TRAEFIK_AUTH` defaults to a value that matches no password (fails closed).
- Certificate: wildcard `*.localhost` plus `EXTRA_HOSTS`. Firefox needs `certs/ca.crt` imported into its own store.
- Dev only: Traefik mounts the Docker socket and `insecure@file` skips backend cert verification.

## Verifying
No test suite. `TRAEFIK_AUTH=x docker compose config -q` validates the compose file; `bash -n up.sh` the script.
Real checks need `./up.sh` and a browser/curl against `https://*.localhost`.
